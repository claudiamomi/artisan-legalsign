3 業務簡報後續補充 Q&A

上週律果科技簡報後，部分同仁針對系統實務應用提出疑慮，律果業務後續補充回覆如下：

Q1 主管是否可以在 Dashboard 上直接看到下屬的工作進度？
A1 Dashboard 上僅可顯示團隊整體的工作數量，無法細分到個人。若需查看個人詳細工作進度，需進入「分析報表」中查詢。
Q2 旅行業 Agent 不一定相信連結或 QR Code，也不會操作該怎麼辦？
A2 可採以下三種應對方式：
① 直接提供 QR Code 給 Agent 端操作；
② 若客戶擔心安全性，請業務現場使用裝置讓客戶簽署，避免不信任連結的疑慮；
③ 可於簽署任務前加入說明頁，告知系統已通過國際級加密與 ISO 27001 認證，安全性無虞。
Q3 其他旅遊業者選擇律果簽的主要原因？
A3 其他旅遊業者選擇律果，主要看中電子簽名使用以及簽署後資料收集的便利性：
・可在平台上傳定型化契約範本
・自由設置簽署框、上傳身分證明文件
・簽署後文件管理、驗證服務一站式完成
Q4 歸檔及存放方式？
A4 可依需求設置不同群組（例如：PO / 業務 / 團別），各自存放完成簽署的任務，並可配置各群組的存取權限，方便團隊管理。
